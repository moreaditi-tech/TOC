THEORY SNAPSHOT

Why a stack?

A Pushdown Automaton (PDA) extends finite-state control with stack memory. Because a stack follows Last In, First Out (LIFO), the last opening tag must be the first one closed.

Opening tag→PUSH→Closing tag→POP
IMPORTANT LIMITATION

Nesting ≠ full validation

This educational simulator checks recognized tag nesting. Real HTML/XML validation includes additional rules. XML tag names are case-sensitive; HTML has special void elements such as <br> and <img>.
